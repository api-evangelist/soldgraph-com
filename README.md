Soldgraph provides a resale data API that aggregates sold and active listings from major marketplaces such as eBay, Poshmark, Mercari, Depop, Whatnot, OfferUp, Facebook Marketplace, Vinted, and also includes TCGplayer card price data. The service scrapes publicly available listing pages, offering JSON endpoints without requiring user authentication to the source marketplaces. It targets developers building market analysis, price tracking, and inventory tools, delivering up-to-date pricing and sales information across multiple regions and categories.

**Areas:** Company · Resale · Marketplace · Pricing · Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for soldgraph-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
